# Exercise 2: Copilot Chat

Here, we have a [python](src/ml_model.py) script for classifying the Iris dataset. 

Use CoPilot Chat what this code does? 

Think yourself about the code quality and how you would possibly refactor it. 

Then, ask CoPilot Chat to refactor the code. Aim for better readability and less redundancy.

### Hints
- Ask how is the code quality? Are there any redundancies in the code? Is it efficient?
- What can be refactored
- What would be a better software architecture for reproducibility?

Can you also have CoPilot Chat write a unittest for the code?
